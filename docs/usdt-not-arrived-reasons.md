## ✅ 先记住一个判断原则

排查 USDT 是否到账时，建议先记住这句话：

> **截图只能参考，链上记录才是依据。**

如果你的收款地址没有对应转入记录，就不要轻易确认到账。

核验时重点看：

| 核对项  | 说明             |
| ---- | -------------- |
| 收款地址 | 是否是你的钱包地址      |
| 交易方向 | 是否为转入          |
| 金额   | 是否和对方说的一致      |
| 时间   | 是否接近对方转账时间     |
| 链类型  | 是否为 TRC20-USDT |
| 交易明细 | 是否能查到链上记录      |

## 🚨 原因一：对方没有真正转账

有时候，对方可能只是说已经转账，但链上并没有真实记录。

常见表现：

* 只发截图，不提供 TxHash
* 截图看起来像转账成功，但地址查不到记录
* 收款地址没有余额变化
* 交易明细里没有对应转入
* 对方一直催促确认到账

这种情况下，应该以你的收款地址交易明细为准。

> [!WARNING]
> 如果收款地址没有对应转入记录，不建议确认到账。

---

## 🚨 原因二：转错地址

USDT 地址通常比较长，复制时容易出错。
如果对方转到了其他地址，你的钱包自然不会到账。

需要核对：

* 对方填写的收款地址是否完整
* 是否和你提供的地址完全一致
* 是否少复制或多复制字符
* 是否复制了旧地址
* 是否把别人的地址当成你的地址

> [!TIP]
> 收款方排查时，优先查询自己的收款地址，看是否有对应转入。

---

## 🚨 原因三：转错链

USDT 有多种网络类型。
如果你要求对方转 **TRC20-USDT**，但对方选择了其他网络，就可能导致你在 TRON 地址上查不到对应记录。

常见问题包括：

* 选错网络
* 把其他链的 USDT 当成 TRC20-USDT
* 地址格式和网络不匹配
* 在错误链上查询交易
* 钱包显示转出，但当前地址没有到账

> [!CAUTION]
> TRC20-USDT 通常使用 TRON 网络，TRON 地址一般以 `T` 开头。查询时一定要确认链类型。

---

## 🚨 原因四：交易还在确认中

有些转账可能不是立刻完成，链上确认和数据同步可能存在短暂延迟。

这种情况下，可能会出现：

* 对方已经发起转账
* 钱包暂时没显示
* 查询工具暂时没有同步
* 几分钟后才显示记录
* 交易状态还没有最终确认

如果刚刚转账，可以稍等一会儿再查询。
但等待期间也不要只凭截图确认到账。

---

## 🚨 原因五：截图是旧交易

有些截图可能不是当前这笔交易，而是以前的转账记录。

判断方法：

* 看截图时间
* 看金额是否一致
* 看地址是否一致
* 看 TxHash 是否对应
* 查询自己的收款地址最近交易明细

如果截图时间和当前订单不匹配，就要谨慎处理。

> [!NOTE]
> 旧截图、相似金额截图和裁剪截图，都可能造成误判。

---

## 🚨 原因六：金额相似但不是同一笔

商家、客服或财务在处理多笔订单时，可能会遇到多个相似金额的转账。

例如：

* 多个用户同时付款
* 多笔金额接近
* 多个订单使用同一个收款地址
* 截图金额和某笔记录相似

这时不要只看金额，还要核对：

| 核对项    | 说明         |
| ------ | ---------- |
| 时间     | 是否接近当前付款时间 |
| 方向     | 是否为转入      |
| 地址     | 是否进入你的收款地址 |
| 金额     | 是否完全一致     |
| TxHash | 是否为当前交易    |

金额相似不代表是同一笔交易。

---

## 🚨 原因七：只看对方转出，没有看自己转入

对方钱包显示“转出成功”，并不代表你的钱包已经收到。

对于收款方来说，真正重要的是：

> **自己的收款地址是否有对应转入记录。**

所以核验时不要只看对方的钱包截图，而要查询你的收款地址交易明细。

---

## 🚨 原因八：TxHash 对应的收款地址不是你的地址

有时候对方会提供 TxHash，但这笔交易并没有转入你的地址。

收到 TxHash 后，需要继续核对：

* 交易是否成功
* 收款地址是不是你的地址
* 转账金额是否一致
* 链类型是否正确
* 时间是否匹配

> [!IMPORTANT]
> TxHash 可以帮助定位交易，但不能单独证明已经到账。

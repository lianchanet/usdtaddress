很多人在核验 USDT 或 TRX 转账时，都会听到一个词：**TxHash**。
它也叫 **交易哈希、交易 ID、Transaction Hash、Transaction ID**。

有些人会认为：

> 有 TxHash，就说明已经到账。

其实这并不完全准确。

**TxHash 可以帮助定位一笔链上交易，但不能单独证明已经到账。**
是否真正到账，还要看这笔交易是否成功、是否转入你的钱包地址、金额是否一致、链类型是否正确。

**链查** 可以帮助用户通过钱包地址查看 USDT / TRX 余额、交易记录和明细。
即使没有 TxHash，也可以通过地址查询来核验是否到账。

> [!IMPORTANT]
> **TxHash 是线索，不是最终到账凭证。钱包地址交易明细才是核验重点。**

---

## 🔍 什么是 TxHash？

TxHash 可以理解为一笔链上交易的唯一编号。

它就像快递单号一样，可以帮助你找到对应的一笔转账记录。

常见叫法包括：

* TxHash
* 交易哈希
* 交易 ID
* Transaction Hash
* Transaction ID
* 链上交易编号

如果对方提供 TxHash，你可以用它辅助查找交易。
但最终仍然要核对交易详情。

> [!TIP]
> TxHash 可以帮你找到交易，但不能直接说明这笔钱已经进入你的地址。

---

## ❓ 有 TxHash 就一定到账了吗？

不一定。

TxHash 只能说明存在一笔链上交易记录，不能单独证明这笔钱已经进入你的地址。

还需要继续核对：

| 核对项  | 说明                |
| ---- | ----------------- |
| 交易状态 | 是否成功              |
| 收款地址 | 是否是你的钱包地址         |
| 金额   | 是否和对方说的一致         |
| 时间   | 是否匹配              |
| 链类型  | 是否为正确网络           |
| 资产类型 | 是否为对应的 USDT 或 TRX |

所以，TxHash 是线索，不是最终结论。

> [!WARNING]
> 如果 TxHash 对应的收款地址不是你的地址，即使交易成功，也不能算你已经到账。

## 📌 TxHash 和钱包地址有什么区别？

| 项目     | 作用            |
| ------ | ------------- |
| TxHash | 定位某一笔交易       |
| 钱包地址   | 查看某个地址的全部相关交易 |
| 交易明细   | 判断转入、转出、金额和时间 |
| 地址余额   | 查看当前资金结果      |

简单理解：

* TxHash 更像一笔交易的“单号”
* 钱包地址更像你的“账户”
* 交易明细是账户流水
* 余额是最终结果

> [!NOTE]
> 核验到账时，不能只看单号，也要看账户是否真的收到。

以下场景中，TxHash 会很有用：

* 对方坚持说已经转账

但即使有 TxHash，仍然要核对收款地址和金额。

## 🚨 常见误区

### 误区一：有 TxHash 就等于到账

错误。
TxHash 只能说明有一笔交易，需要进一步确认是否转入你的地址。

---

### 误区二：对方截图显示成功就一定到账

不一定。
截图可能是转出成功，但资金不一定进入你的收款地址。

---

### 误区三：没有 TxHash 就完全查不了

错误。
通过钱包地址查询，同样可以查看最近交易记录和余额变化。

---

### 误区四：金额相似就认为是同一笔

不建议。
还要核对时间、方向、地址和链类型。

---

### 误区五：只看对方转出，不看自己转入

对方地址显示转出，不代表你的地址已经收到。
对收款方来说，重点是自己的收款地址有没有对应转入。

> [!CAUTION]
> 核验到账时，不要只看“交易成功”，还要看“是否转入你的地址”。

## 为什么查不到 TRC20-USDT 记录？

如果你没有查到记录，常见原因包括：

* 钱包地址输入错误
* 对方没有真正转账
* 转错链，不是 TRON 网络
* 转到了其他地址
* 交易还在确认中
* 数据同步有延迟
* 对方给的是截图，不是链上真实记录
* 查的是 TxHash，但没有核对收款地址

遇到这种情况，建议先重新核对地址、链类型、金额和时间，再查询钱包地址交易明细。

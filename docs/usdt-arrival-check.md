## 🧭 常见情况怎么判断？

### 情况一：余额变了，交易明细也有对应转入

这种情况一般说明已经到账。
你可以继续核对金额、时间和地址，确认是否与对方转账信息一致。

---

### 情况二：余额没变，交易明细也没有对应转入

这种情况通常说明还没有到账。

可能原因包括：

* 对方没有真正转账
* 对方转错地址
* 对方转错链
* 交易还未确认完成
* 钱包地址填写错误
* 网络或数据同步延迟

> [!WARNING]
> 如果你的地址没有对应转入记录，不要只凭截图确认到账。

---

### 情况三：有交易记录，但金额不一致

如果交易明细中有转入记录，但金额和对方说的不一致，需要继续核对是否为同一笔交易。

重点看：

* 时间是否一致
* 金额是否一致
* 对方地址是否一致
* 是否存在多笔相似金额交易

不要因为金额相近就默认是同一笔。

---

### 情况四：对方给了 TxHash，但地址没有收到

TxHash 可以帮助定位交易，但不代表一定转入你的地址。

还需要核对：

| 核对项  | 说明      |
| ---- | ------- |
| 交易状态 | 是否成功    |
| 收款地址 | 是否是你的地址 |
| 转账金额 | 是否一致    |
| 链类型  | 是否正确    |
| 交易时间 | 是否匹配    |

> [!CAUTION]
> TxHash 是线索，钱包地址交易明细才是核验重点。

## 📸 为什么不建议只看转账截图？

转账截图有几个明显问题：

* 可能不是当前这笔交易
* 可能不是转给你的地址
* 可能金额相似但不是同一笔
* 可能只是发起转账，不代表成功到账
* 图片可能被裁剪或修改
* 无法直接证明链上真实入账

所以在 USDT 到账核验时，建议始终回到链上记录。

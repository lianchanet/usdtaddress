## ✅ 2. USDT 到账怎么判断？

判断 USDT 是否到账，建议重点看 5 个信息：

* 收款地址是否正确
* 是否存在对应转入记录
* 金额是否一致
* 时间是否接近
* 链类型是否正确

如果你的收款地址里有对应的转入记录，并且金额、时间、地址都能对应上，一般可以认为这笔交易已经到账。

> [!TIP]
> 对收款方来说，重点不是对方有没有截图，而是你的地址是否真的有对应转入。

## 📸 3. 对方发了转账截图，可以直接确认到账吗？

不建议。

转账截图只能作为参考，不能作为最终到账凭证。

截图可能存在以下问题：

* 截图是旧交易
* 截图不是转给你的地址
* 金额相似但不是同一笔
* 截图只显示对方转出
* 图片被裁剪或修改
* 转错链或转错地址
* 交易尚未真正完成

> [!WARNING]
> 截图不能代替链上记录。确认到账时，应该查询自己的收款地址交易明细。

## 🧾 4. 有 TxHash 就一定到账了吗？

不一定。

TxHash 可以理解为一笔链上交易的编号，可以帮助定位某一笔交易。
但有 TxHash 并不代表这笔钱一定进入了你的地址。

还需要继续核对：

| 核对项  | 说明        |
| ---- | --------- |
| 交易状态 | 是否成功      |
| 收款地址 | 是否是你的钱包地址 |
| 金额   | 是否一致      |
| 链类型  | 是否正确      |
| 时间   | 是否匹配      |

如果 TxHash 对应的收款地址不是你的地址，即使交易成功，也不能算你已经到账。

> [!NOTE]
> TxHash 是线索，钱包地址交易明细才是核验重点。

## 🔗 5. TRC20-USDT 是什么意思？

TRC20-USDT 是运行在 TRON 网络上的 USDT。

常见特征包括：

* TRON 地址通常以 `T` 开头
* 很多 USDT 收款场景使用 TRC20 网络
* 查询时需要确认链类型
* 转账记录可以通过钱包地址或 TxHash 查看

如果对方转错链，或者你查询的网络不对，可能会导致查不到对应记录。

## ❌ 6. 为什么 USDT 查不到到账记录？

常见原因包括：

* 对方没有真正转账
* 钱包地址输入错误
* 对方转错地址
* 对方转错链
* 交易还在确认中
* 数据同步有延迟
* 查询的不是自己的收款地址
* 截图不是当前这笔交易
* TxHash 对应地址不是你的地址

遇到这种情况，不要着急确认到账，建议先重新核对地址、链类型、金额和时间。

## 💰 7. 余额变了就一定没问题吗？

余额变化是重要参考，但最好同时看交易明细。

建议同时核对：

* 余额是否变化
* 是否有对应转入记录
* 金额是否一致
* 时间是否接近
* 收款地址是否正确
* 交易方向是否为转入

如果只是余额变化，但没有核对明细，仍然可能出现误判。

## 🔁 8. 转入和转出怎么区分？

对收款方来说，需要重点看是否为 **转入**。

简单理解：

| 方向 | 含义         |
| -- | ---------- |
| 转入 | 资金进入该钱包地址  |
| 转出 | 资金从该钱包地址转走 |

如果你是收款方，只有资金进入你的地址，才算和你有关的到账记录。

> [!CAUTION]
> 对方地址显示转出，不代表你的地址已经收到。一定要查自己的收款地址。

## 🧑‍💼 9. 商家怎么核对 USDT 收款？

商家建议按下面流程操作：

1. 复制自己的收款钱包地址
2. 打开链查查询地址
3. 查看最近交易明细
4. 核对是否有对应转入
5. 核对金额和时间
6. 如有 TxHash，继续辅助核验
7. 地址无对应记录时，不要确认到账

这样可以减少假截图、旧截图、错链、错地址和未到账带来的风险。

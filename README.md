## 📌 为什么不要只看转账截图？

转账截图只能作为参考，不能作为最终凭证。

常见问题包括：

* 截图可能不是当前这笔交易
* 截图金额相似但地址不一致
* 对方发的是转出截图，但没有转到你的地址
* 交易还未真正完成确认
* 转错链、转错地址或网络延迟
* 图片可以伪造，链上记录更可靠

所以核验 USDT 到账时，更建议通过钱包地址查询交易明细。

一句话：

> **别信截图，信链上。余额看结果，明细看证据。**

## ❓ 常见问题

### 1. 对方说已经转账，但我没有收到怎么办？

先不要只看截图。
建议打开链查，输入你的收款地址，查看余额是否变化，以及交易明细中是否有对应转入记录。

如果余额没变，交易明细也没有对应转入，大概率说明还没有真正到账，或者地址、网络、链类型存在问题。

---

### 2. 有 TxHash 就一定到账了吗？

不一定。

TxHash 可以帮助定位一笔交易，但最终还要看：

* 是否转入你的地址
* 金额是否一致
* 时间是否匹配
* 交易是否成功
* 链类型是否正确

所以 TxHash 是线索，钱包地址交易明细才是核验重点。

---

### 3. 没有 TxHash 可以查吗？

可以。

如果没有交易哈希，也可以通过钱包地址查询。
输入收款地址后，查看最近交易记录、余额变化和是否存在对应转入。

---

### 4. 为什么我查不到记录？

常见原因包括：

* 钱包地址输入错误
* 查询的链不对
* 对方没有真正转账
* 交易还在确认中
* 网络或接口同步延迟
* 对方转到了其他地址

可以稍后再次查询，或者核对地址、链类型和转账时间。
